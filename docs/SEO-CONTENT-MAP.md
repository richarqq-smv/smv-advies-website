## Search Console

**Er is geen Search Console-data beschikbaar via de repository of deze sessie.** Er is geen connector, export, of eerder vastgelegde data aangetroffen. Dit moet expliciet zo blijven totdat een sessie met daadwerkelijke Search Console-toegang dit kan aanvullen — verzin geen impressies, CTR, posities of zoekopdrachten.

Zodra Search Console-toegang beschikbaar is, moet een toekomstige fase minimaal analyseren:
- impressies en CTR per pagina;
- posities per zoekopdracht, met name pagina's op positie 5–20 (grootste quick-win-potentieel);
- CTR-kansen (hoge impressies, lage CTR — vaak een title/meta-descriptieprobleem);
- mogelijke cannibalisatie tussen bestaande artikelen (twee pagina's die voor dezelfde zoekopdracht concurreren);
- nieuwe, nog onbehandelde zoekintenties die al wel impressies genereren.
